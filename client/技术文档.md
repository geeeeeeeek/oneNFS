# oneNFS 项目指南
 

---

## 一、项目概述

### 这是什么项目？

oneNFS 是一个 **Web3 音乐流媒体平台**，类似于"区块链版的网易云音乐"。

**核心功能：**
- 用户可以上传音乐并铸造为 NFT
- 其他用户可以购买或租赁音乐
- 使用加密货币进行交易
- 所有权和交易记录永久保存在区块链上

**技术亮点：**
- 基于 Next.js 14 构建的现代化前端
- 使用 Privy 实现 Web3 钱包登录
- 与 Polygon 区块链智能合约交互
- Redux 管理全局音乐播放状态

```

    ▼

    │
    ├── 未连接 ──────► 显示登录按钮
    │                      │
    │                      ▼
    │                 点击连接钱包
    │                      │
    │                      ▼
    │                 Privy 弹出钱包选择
    │                      │
    │                      ▼
    │                 用户授权连接
    │                      │
    └── 已连接 ◄───────────┘
          │
```

### 4.3 BottomAudioPlayer（音频播放器）

**文件位置：** `src/components/bottom-audio-player.js`

功能：
- 播放/暂停控制
- 进度条和时间显示
- 上一首/下一首
- 随机播放和循环模式
- 音量控制

```javascript
function BottomAudioPlayer() {
  const audioRef = useRef(null);
  const { uri, isPlaying } = useSelector(state => state.musicPlayer);

  useEffect(() => {
    if (uri) {
      audioRef.current.src = uri;
      if (isPlaying) audioRef.current.play();
    }
  }, [uri, isPlaying]);

  return (
    <div className="fixed bottom-0">
      <audio ref={audioRef} />
      {/* 播放控制 UI */}
    </div>
  );
}
```

## 六、常见问题解答

### Q: 为什么用 Polygon 而不是以太坊主网？
A: Polygon 是以太坊的 Layer 2 网络，Gas 费用极低（几分钱），交易确认快（几秒），非常适合高频小额交易的音乐平台。

### Q: Privy 是什么？
A: Privy 是一个 Web3 认证服务，简化了钱包连接流程，支持多种钱包（MetaMask、Rainbow等），还能为没有钱包的用户自动创建嵌入式钱包。

### Q: 为什么用 Redux 而不是 Context？
A: 音乐播放器需要在多个组件间共享状态（当前歌曲、播放状态等），Redux 提供了更好的状态管理和调试体验。

### Q: 智能合约做了什么？
A:
- **oneNFS 合约**：管理音乐 NFT 的铸造、购买、租赁、版税分配
- **MusicX 合约**：平台代币，用于支付和奖励
